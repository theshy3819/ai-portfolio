# 송호영 · AI Service Portfolio

기술을 구현하고, 사업으로 연결하는 AI 서비스 개발자 송호영의 포트폴리오입니다.

- 사이트: https://theshy3819.github.io/ai-portfolio/
- 구성: 핵심 역량 · 이력 · 스킬 · 프로젝트(Lumi · COSMOS · 주만추) · AI 사업 기여 방향 — A4 가로 14쪽
- 화면에서는 ↑·↓로 한 쪽씩 넘기고, 인쇄(Ctrl+P → A4 가로, 여백 없음, 배경 그래픽 켜기)하면 쪽당 A4 한 장으로 나옵니다.

## 개발

```bash
npm install
npm run dev
```

Vue 3 + Vite. 내용은 `src/content.js` 한 파일에서 고칩니다. `main`에 올리면 GitHub Actions가 Pages로 자동 배포합니다.
